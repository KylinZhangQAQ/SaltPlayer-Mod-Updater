# 模组更新中心 1.7.2

发布日期：2026-11-24

本次更新修复安装失败后的插件恢复问题，并完善字体选择和缓存清理。

## 修复

- 修复部分插件更新失败后从模组列表消失的问题。
- 更新失败时优先保留可恢复的旧版本。
- 已完成或已失败的安装任务会自动清理，不再长期占用磁盘空间。
- 等待中的安装任务不会受影响。

## 优化

- 字体设置会显示仅为当前用户安装的字体。
- 同一字体同时为用户和所有用户安装时只显示一次。
- 删除其中一种安装后，只要另一种仍在，字体仍会保留。

## 安装

下载 `plugin-dev.saltupdater-1.7.2.spmod`，在 Salt Player 的模组管理中导入并启用。
