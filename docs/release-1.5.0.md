# 模组更新中心 1.5.0

发布日期：2026-11-11

1.5 是一次面向日常使用的大版本，重点放在更新流程、插件市场阅读体验和字体缩放适配上。

## 新增

- 安装成功后自动清理下载的 `.spmod`；安装失败会保留文件，重启后可直接复用，避免重复下载。
- 更新后首次打开更新中心时，如果下载目录还有遗留下载包：
  - 已安装插件的旧缓存会询问是否删除；
  - 未安装插件的缓存会询问是否直接安装；
  - 删除前显示具体文件路径；
  - 下载目录为空时不弹窗。
- 插件市场 README 支持 emoji、链接和文本排版，自动铺满右侧卡片并可滚动阅读。
- README 标题栏的「更多」可直接打开 GitHub 网页版 README；应用内 README 保留。
- 详情页的「检查更新 / 更新 / 发布页 / 设置仓库」改为四个独立按钮。
- 市场分类在字体缩放后自动换行，不再裁掉「其他」等分类。
- 设置支持 85%–125% 字体缩放。

## 优化

- README 与更新日志使用同一套字号和标题比例，标题不再偏大。
- 窗口自由缩放时，右侧 README/更新日志跟随高度铺满。
- Steam 详情介绍与 GitHub 详情保持相同的标题、正文和来源提示布局。
- 计数行、README 标题、分类行、详情头部会跟随文字高度变化，减少裁切。
- 左侧列表的「更多」改为打开 GitHub README 网页，不再重复选中行。

## 修复

- 修复 85% 缩放时 README 图标、计数文字贴边裁切。
- 修复窗口变窄后分类换行但行高不增长。
- 修复 README 长行超出右侧边界。
- 修复自由缩放窗口时右侧内容闪烁、高度不更新。
- 修复部分比例下详情正文、来源信息或链接行消失。

## 安装

下载 `plugin-dev.saltupdater-1.5.0.spmod`，在 Salt Player 的模组管理中导入并启用。
