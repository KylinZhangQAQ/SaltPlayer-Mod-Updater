# 模组更新中心 1.6.8

发布日期：2026-11-16

1.6.8 优化自更新体验。

## 优化

- 自更新跳过直接替换，直接准备关闭后安装。
- 准备阶段显示实际解压进度，不再长时间只显示“安装中”。
- 解压完成后自动退出并重启。
- 非自更新插件仍然优先直接安装。

## 保留

- Java staging 解压，支持长路径。
- 等待所有 Salt Player 进程退出，连续 5 秒静默后替换。
- 批量任务只在最后完成时重启一次。
- 安装成功清理下载包，失败保留缓存。

## 安装

下载 `plugin-dev.saltupdater-1.6.8.spmod`，在 Salt Player 的模组管理中导入并启用。
