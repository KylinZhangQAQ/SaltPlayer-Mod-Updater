# 模组更新中心 1.6.0

发布日期：2026-11-14

1.6 重点改善版本选择、更新控制和界面一致性。

## 新增

- 市场安装按钮升级为分裂按钮：默认安装最新版本，右侧箭头可选择任意历史版本。
- 历史版本菜单显示版本号、发布时间和是否有可安装包；没有安装包的版本会明确置灰。
- 「打开仓库」直接进入 Release 页面，「更多」继续用于打开 README 网页。
- 支持识别可安装的 `.zip` 插件包；只有源码、没有插件清单的 ZIP 会被拒绝。
- 已安装插件支持忽略本次、永久忽略和恢复更新。
- 下载管理只显示真实下载/安装任务。

## 优化

- 左侧卡片改为异形轮廓：主体圆角矩形，两个标签页向上突出。
- 标签页尺寸和对比度降低，选中项与主体融合，不再出现重复描边和割裂色块。
- 列表竖线会跟随右侧操作区宽度自动移动。
- 分类固定六列一行，125% 字体下所有分类完整显示，行高恢复 44px。
- README、更新日志、详情标题和计数行继续适配字体缩放。

## 修复

- 修复选择「安装并重启」后直接安装成功却不重启。
- 修复市场下载进度条不按实际百分比前进。
- 修复下载管理混入检查中、已是最新等非下载任务。
- 修复下载管理移除按钮样式不一致。
- 修复标签交界处圆角与描边错位。

## 安装

下载 `plugin-dev.saltupdater-1.6.0.spmod`，在 Salt Player 的模组管理中导入并启用。
