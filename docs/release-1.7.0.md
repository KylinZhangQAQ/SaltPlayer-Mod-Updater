# 模组更新中心 1.7.0

发布日期：2026-11-21

1.7.0 新增可操作的安装备份恢复功能。

## 新增

- 安装备份写入元数据 `backup.json`，记录插件、版本、时间和旧安装包。
- 设置 → 备份管理新增「恢复备份」。
- 恢复前为当前版本创建新的安全备份。
- 运行中文件被占用时转为关闭后恢复。
- 恢复复用安装事务、deferred、rollback 和重启预算。
- 旧格式或缺失旧包的备份标记为不可恢复。

## 优化

- 恢复按钮改为紧凑尺寸，行内垂直居中。
- 备份恢复窗口适配深色模式、100%/125% 字体和不同 DPI。
- 版本和时间分两行显示，避免 125% 下被裁切。
- 正式版本固定 `x.x.x`；内部测试包使用 `build.ps1 -Test`，文件名追加 `-test.yyyyMMddHHmm`，manifest 保持外部版本。

## 安装

下载 `plugin-dev.saltupdater-1.7.0.spmod`，在 Salt Player 的模组管理中导入并启用。
