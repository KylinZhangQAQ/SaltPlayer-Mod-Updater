## 验收规则

- 每个阶段先构建，再跑 `SelfTest`。
- 视觉阶段必须提供深/浅色截图。
- 字体阶段必须覆盖默认字体、系统字体、思源黑体，以及 85% / 100% / 125%。
- 所有阶段通过后才发布 GitHub Release；发布资产 SHA 必须与宿主安装一致。
