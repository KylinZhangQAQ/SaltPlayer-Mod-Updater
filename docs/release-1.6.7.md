# 模组更新中心 1.6.7

发布日期：2026-11-16

1.6.7 修复另一台慢电脑上关闭后安装、长路径和自动重启失败的问题。

## 修复

- 安装包在退出前由 Java 解压到 staging，后台助手只移动已解压目录，不再依赖 PowerShell ZIP 解压。
- 后台安装等待所有 Salt Player 进程退出，并要求连续 5 秒无应用进程后再开始替换。
- 多个关闭后安装任务只在全部完成后重启一次。
- 自动重启优先通过固定 AppId 的 MSIX `shell:AppsFolder` 入口启动。
- 安装期间阻止旧状态页面和自动检查，避免再次提示旧版本。
- 安装成功清理下载包，失败保留缓存。

## 安装

下载 `plugin-dev.saltupdater-1.6.7.spmod`，在 Salt Player 的模组管理中导入并启用。
