# 模组更新中心 1.6.10

发布日期：2026-11-20

1.6.10 完成多分辨率、DPI 和字体缩放适配，保持现有排列和视觉结构不变。

## 修复

- 详情标题高度、徽标尺寸随字体缩放，长标题不再被裁切。
- 窄宽度下标题自动缩小字体而不是硬裁切。
- 排序按钮宽度随字体缩放，弹出菜单与按钮同宽、左对齐。
- 排序菜单项高度与内边距统一缩放，125% 下不再错位。
- 分类行优先保留排序按钮位置，避免窄窗口挤掉排序入口。
- 最小窗口宽度按字体缩放调整，改善 1080p/125% 的布局。
- 标签页 hover/点击统一由父卡片处理，完整标签区域都有反馈。
- 排序下拉勾选改为矢量绘制，菜单项直接加入 JPopupMenu，鼠标移入不会关闭。
- 左上圆角限制在标签左边距以内，修复描边回穿标签。

## 已验证

- 1280×800 / 100%
- 1280×800 / 125%
- 1400×900 / DPI 125% / 字体 100%
- 1920×1080 / 125%
- 深色主题 / DPI 125%

## 安装

下载 `plugin-dev.saltupdater-1.6.10.spmod`，在 Salt Player 的模组管理中导入并启用。
